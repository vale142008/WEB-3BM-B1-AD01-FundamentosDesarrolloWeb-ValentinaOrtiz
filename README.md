# AutoVale - Taller Automotriz

Proyecto desarrollado para la materia de Fundamentos de Desarrollo Web.

## Descripción
Sistema web para taller automotriz (**AutoVale**), que incluye gestión de servicios, cotizaciones, citas de inspección y administración de servicios/cuentas.

## Estructura del Proyecto
- `index.html`: Página principal con presentación de servicios, catálogo y calculadora/cotizador.
- `inscripcion.html`: Formulario para solicitar citas e inscripción de vehículos.
- `cuenta.html`: Vista de perfil y gestión de cuenta del usuario.
- `admin.html`: Panel administrativo para visualización y gestión.
- `css/styles.css`: Hoja de estilos personalizada.
- `js/script.js`: Lógica e interactividad del sistema en frontend.

## Tecnologías utilizadas
- HTML5
- CSS3 / Bootstrap 5
- JavaScript (ES6)
- FontAwesome Icons
